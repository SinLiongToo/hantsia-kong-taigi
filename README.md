# 番薯仔講台語 Han-tsî-á Kóng Tâi-gí

《番薯仔大冒險》的進階版：學過子音、母音了後，這馬來學**講句仔**。

**線頂耍：** https://sinliongtoo.github.io/hantsia-kong-taigi/

## 四種玩法

| 玩法 | 內容 |
|---|---|
| 📖 **學堂** | 33 課。**語法課 25 課**：人稱、是／毋是、有／無、欲、咧、句尾「矣」、會／袂、敢、共、予、佇、甲、較、問代誌、攏、嘛、閣、就、才、猶未／未、莫／毋通、佮、的、量詞、程度（真／誠／傷）——逐課有說明、詞卡、辭典例句，會使「排 5 句」抑是「填空 5 題」。**詞彙課 8 課**：相借問、數字、家人、時間、食物、動物、身軀、色水佮形容——詞卡＋8 題選擇題（華語⇄台語）。照毋著的次數得 1～3 粒星 |
| 🧩 **排句仔** | 看華語意思，共台語詞卡排做正確的句。初級／中級／高級，三粒心，排毋著兩擺扣一粒，連續排著有加分。中級加一張、高級加兩張「陷阱詞卡」（像「無／毋」「欲／愛」「咧／佇」這款易混的詞） |
| ✏️ **填空** | 辭典例句挖掉一个語法詞，四个選項揀一个。一輪 10 題，對 24 課（857 題）抽。量詞課的選項攏是量詞 |
| 🎰 **造句機** | 三種句型：**動作句**（主語 15＋時間 9＋嘛／攏／閣／猶閣＋欲／咧／有… 9＋地點 8＋動作 51＋句尾）、**形容句**（主語 17＋真／誠／足／傷／較／無…＋形容 27，例：「這碗麵真燒」）、**比較句**（「我比伊較懸」「我佮伊平懸」，會使用「敢」問）。番薯仔會共你講自然無、哪位怪怪（例：「天氣真燒」→ 天氣愛講「熱」；「佇房間開車」→ 空間無夠）。自然的句會使收入「句仔簿」。逐種句型攏有「挑戰」模式：看華語，用造句機組出來（8 題） |

設定：漢字＋羅馬字／干焦漢字／全羅、台羅／白話字、華語提示開關、音效。進度存佇瀏覽器（localStorage）。

操作：點詞卡排上去，點排好的詞卡會退轉來。鍵盤 Enter 檢查／下一題，Backspace 退一張。

## 資料來源佮限制（重要）

- **例句**：全部對教育部《臺灣台語常用詞辭典》開放資料（[g0v/moedict-data-twblg](https://github.com/g0v/moedict-data-twblg)）的例句擷取，漢字、台羅、華語翻譯攏是辭典原文。漢字佮台羅用音節數對齊切做詞卡，對袂齊的句（約 20 句）、歇後語、有羅馬字夾雜的句、有粗俗字的句攏提掉。
- **詞彙**：學堂的詞卡、詞彙課、填空選項、造句機的每一个詞，建置的時攏對辭典查證漢字佮讀音，查無就建置失敗。「你好」「免客氣」「食飽未」「阿嬤」「芎蕉」「機車」辭典無收做詞條，所以無用。造句機的「食飯」「看冊」這款組合辭典無收，所以拆做「食」＋「飯」逐个查。
- 「佮」辭典有 kah、kap 兩个讀音，例句攏寫 kah，所以課文照 kah 教。
- 初級／中級例句少過 15 句的課，有補 6 張詞卡以內的高級例句。
- **以下是 AI 整理的，毋是官方資料**：
  - 學堂逐課的說明文字（語法教學筆記）
  - 難度分級（照詞卡數佮詞的出現次數用程式規則分）
  - 造句機「自然無」的判斷規則（例：「明仔載」毋配「有／咧／捌」）。實際講話有時較活，規則是為著教學簡化的
  - 造句機的華語翻譯（照詞逐个組起來）
  - 造句機的華語翻譯、「主語佮形容詞配毋配」的分類（人／動物／食物／天氣／所在）
  - 造句機句尾「無？」寫做輕聲「--bô」，是參考辭典例句「好--無？」的寫法
- 排句仔干焦接受辭典原本的詞序。有寡句換一个詞序嘛通，毋過遊戲會算毋著——看答案的時會顯示辭典原句。
- 介面上的羅馬字（按鈕、標題），辭典有收的詞照辭典；辭典無收的複合詞（像「人稱」「填空」）是 AI 寫的。
- 無聲音：瀏覽器無通用的台語語音，所以這版無發音。
- 例句以辭典為準，各地腔口有差。

## 檔案

```
index.html           遊戲本體（無框架、無需要安裝，雙擊就會使耍）
data/sentences.js    建置產生的資料（毋通手改）
tools/build-data.js  建置腳本
```

重新產生資料（辭典檔預設讀隔壁專案 `project_claude_TG_game/data/raw/`，只讀無改）：

```bash
node tools/build-data.js [dict-twblg.json 路徑]
```
